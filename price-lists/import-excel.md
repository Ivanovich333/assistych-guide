# Прайс файлом: загрузка из Excel

Если услуг много, удобнее заполнить таблицу в Excel, чем вносить их по одной. Загрузка работает с файлами .xlsx. Формат CSV в кабинете для прайса не предусмотрен.

## Как загрузить

1. Откройте «Прайс-листы» и нужный прайс, вкладку «Категории и услуги».
2. Нажмите «Скачать шаблон». Скачается файл .xlsx. Если в прайсе уже есть услуги, они будут в файле, и его можно использовать как выгрузку.
3. Заполните или поправьте строки в Excel, не меняя названия колонок.
4. Нажмите «Загрузить файл», перетащите .xlsx в окно или выберите файл. Максимальный размер 10 МБ.
5. Нажмите «Импортировать». Кабинет покажет «Импорт завершён»: сколько услуг «Создано», сколько «Обновлено» и список ошибок по строкам.

[скрин: вкладка «Категории и услуги» с кнопками «Скачать шаблон» и «Загрузить файл»]

## Какие колонки

Читается только первый (активный) лист. В шаблоне есть лист «Services» с данными и лист «Instructions» с подсказками на английском.

| Колонка | Нужна ли | Что писать |
|---|---|---|
| `name` | обязательна | Название услуги |
| `category_name` или `category_display_name` | нужна одна из двух в каждой строке | Категория. Если пишете только отображаемое название, короткое имя создастся само |
| `price_class_1`, `price_class_2` и дальше | по желанию, только если в прайсе есть классы (например, классы авто) | Цена для каждого класса, целое число в рублях. Классов не больше 6 |
| `price_fixed` | по желанию | Фиксированная цена |
| `price_from` | по желанию | Цена «от» |
| `agent_notes` | по желанию | Заметки для агента, например «при сильном загрязнении дороже» |

Используйте либо фиксированную цену, либо «от», не обе сразу.

## Что происходит с уже внесённым

- Импорт только добавляет и обновляет. Услуга ищется по паре «категория и название» без учёта регистра: нашлась, значит обновится, не нашлась, значит создастся.
- Услуги, которых нет в файле, не удаляются. Чтобы убрать услугу, удалите её в кабинете.
- Новые категории из файла создаются сами.
- Строки без названия пропускаются без сообщения.
- Строка с ошибкой не мешает остальным: все корректные строки сохранятся, а ошибки покажутся списком вида «Row 5: …». Тексты ошибок приходят на английском.
- В числах цены оставляйте только цифры. Если в ячейке текст вместо числа, цена останется пустой без ошибки, проверяйте результат.

## Если что-то пошло не так

- «Не удалось импортировать файл». Проверьте, что это .xlsx до 10 МБ и колонки шаблона на месте. Особенно колонка `name`.
- «Missing 'name' column». В файле нет колонки `name`: скачайте шаблон заново.
- «Missing category_name and category_display_name». В этой строке нет категории.
- Услуга создалась без цены. Импорт цену не требует, поэтому такие строки проходят. Откройте прайс и проверьте пустые цены.
