# Звонки

Раздел **Звонки** — все входящие звонки из коллтрекинга Авито: записи разговоров, ИИ-анализ содержания и план дожима по каждому звонку. Данные обновляются каждые полчаса, записи хранятся у Авито 3 месяца.

{% hint style="info" %}
Авито отдаёт только **входящие** звонки. Исходящие (перезвон менеджера с обычного телефона) в отчёт не попадают — отметьте результат сами кнопкой «Перезвонили», дата и время запишутся одним нажатием.
{% endhint %}

## Куда утекают клиенты

Два фильтра сверху отвечают на главный вопрос:

* **«Кого дожать»** — по анализу звонка клиент ждёт перезвона или следующего шага.
* **«Пропущенные без ответа»** — звонок пропущен, и после него клиент больше не появлялся (пометка «нет контакта»).

## Анализ звонка

Кнопка **«Проанализировать»** запускает разбор записи (можно сразу несколько выбранных). Через минуту-две у звонка появляются:

* **Итог**: сделка / консультация / перезвонить / потерян / неясно.
* **Транскрипт** разговора.
* **Ошибки** оператора и **план действий** — что сделать, чтобы дожать клиента, включая готовую фразу для реактивации (копируется одной кнопкой).

Если анализ не нужен повторно — всегда можно «Переанализировать». Заметки («перезвонил, договорились на четверг») добавляются к каждому звонку.
