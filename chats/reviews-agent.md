# Агент ответов на отзывы

Готовый агент из **Магазина**, который сам отвечает на отзывы вашего аккаунта Авито. Ставится в один клик: **Магазин → «Агент ответов на отзывы» → Установить**.

![Агент ответов на отзывы](../.gitbook/assets/screen-reviews-agent.png)

## Что настраивается

* **Промпт** — как отвечать, каким тоном. Можно править под ваш стиль.
* **Минимальная оценка** — например отвечать только на 5 звёзд, а 4 и ниже оставлять вам.
* **Задержка и дневной лимит** — ответы уходят по одному с интервалом, никогда не пачкой.
* **Пропуск отвеченных** — на отзыв, где уже есть ответ, агент не отвечает повторно.
* **Старые отзывы** — по умолчанию агент отвечает только на новые. Разбор старого бэклога включается отдельным тумблером и идёт постепенно, в рамках дневного лимита.

{% hint style="info" %}
Кнопка **«Предпросмотр»** показывает, как агент ответит на реальный отзыв, ничего не отправляя. Каждый отправленный ответ тарифицируется — примерно один токен за ответ.
{% endhint %}

## Негативные отзывы

По умолчанию агент **не трогает негатив** — такие отзывы остаются вам, чтобы вы ответили лично. При желании можно включить ответ на них отдельным сдержанным промптом.
