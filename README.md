# Добро пожаловать

Assistych помогает вести Авито на автопилоте: импортирует объявления, пишет продающие тексты и фото нейросетью, держит позиции в выдаче и отвечает клиентам за вас.

{% hint style="success" %}
Новичкам хватит трёх шагов ниже, чтобы начать. Остальные разделы можно открывать по мере надобности.
{% endhint %}

## Что умеет сервис

* **Объявления в одном окне** — импорт ваших живых объявлений с Авито и удобное управление.
* **Нейросеть для контента** — продающие заголовки, описания и фото в пару кликов.
* **Города** — клонирование объявления по другим городам.
* **Продвижение** — автоматическое управление ставками, чтобы держать нужную позицию.
* **Чаты** — ИИ-ассистент отвечает покупателям сам, вы подключаетесь когда нужно.
* **Цифры** — расход и статистика по каждому объявлению.
