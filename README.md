# Добро пожаловать

Assistych — это кабинет для управления объявлениями на Авито и общения с клиентами с помощью нейросети.

## Что умеет сервис

* Импорт ваших живых объявлений с Авито в один список.
* Генерация продающих заголовков, описаний и фото нейросетью.
* Клонирование объявления по другим городам.
* Автозагрузка и публикация объявлений на Авито.
* Автоматическое управление ставками продвижения, чтобы держать нужную позицию в выдаче.
* ИИ-ассистент в переписках Авито, который отвечает клиентам за вас.
* Учёт расходов и статистики по каждому объявлению.
