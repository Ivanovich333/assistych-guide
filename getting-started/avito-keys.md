# Client ID и Client Secret Авито: где взять и куда вставить

Чтобы агент отвечал в чатах Авито, Авито должен выдать вам пару ключей для доступа к вашему аккаунту. Это как логин и пароль для программ: «Client ID» и «Client Secret». Ключи ваши, никому их не отправляйте.

## Что нужно заранее

- Аккаунт продавца на Авито с платным тарифом. Без него Авито не даёт доступ к API.
- Подписка на «API мессенджера» в кабинете Авито. Без неё подключение пройдёт, объявления и автозагрузка заработают, но чаты будут недоступны.
- Созданный агент в Assistych: [Как создать агента](../guide/agent/01-kak-sozdat-agenta.md).

С нашей стороны чаты Авито доступны уже на тарифе «Старт» (один аккаунт). Разделы управления объявлениями открываются с тарифа «Авито»: [Тариф и использование](../billing/pricing.md).

## Шаг 1. Получите ключи в Авито

1. Войдите на Авито под нужным аккаунтом и откройте avito.ru/professionals/api (раздел для разработчиков).
2. Создайте доступ к API и скопируйте два значения: «Client ID» и «Client Secret».
3. В кабинете Авито проверьте, что у ключей есть доступ к мессенджеру.

[скрин: страница avito.ru/professionals/api с выделенными Client ID и Client Secret, секрет закрасить]

Точный вид страницы Авито иногда меняется. Если не находите пункт, смотрите справку Авито или напишите нам: support@assistych.ru.

## Шаг 2. Вставьте ключи у нас

1. Откройте «Агенты», нужного агента, вкладку «Интеграции», «Добавить интеграцию», «Авито». Так канал сразу привяжется к агенту. Можно и через меню «Авито» → «Мои аккаунты» → «Подключить аккаунт».
2. Заполните «Название интеграции» (любое, например «Мой магазин Авито»), «Client ID» и «Client Secret».
3. Нажмите «Подключить Авито». Появится «Авито успешно подключён».

[скрин: форма «Подключение Авито» с тремя полями]

Если агента не выбрали, система создаст выключенного «Авито-ассистента». Он молчит, пока вы его не настроите и не включите. После подключения включите автоответы на карточке аккаунта: подробности в [Подключение каналов](../instructions/03-podklyuchenie-kanalov.md).

## Если что-то пошло не так

| Что видите | Что это значит | Что делать |
|---|---|---|
| «Авито не принял ключи» | Ключи неверные или перепутаны | Скопируйте заново, целиком, без пробелов. Частая ошибка: Client ID и Client Secret поменяны местами |
| «Не удалось получить данные аккаунта» | Ключи приняты, но Авито не отдал сведения об аккаунте | Проверьте на avito.ru/professionals/api, что доступ к API активен и у аккаунта платный тариф |
| «Не удалось подключить Авито» | Авито не ответил | Подождите пару минут и повторите |
| «Чаты Авито недоступны: в вашем тарифе Авито нет API мессенджера» | Нет подписки на API мессенджера | Подключите её в кабинете Авито и нажмите «Проверить снова» у аккаунта |
| «Ключи Авито не дают доступ к чатам» | У ключей нет доступа к мессенджеру | Выдайте ключам доступ к мессенджеру в кабинете Авито и нажмите «Проверить снова» |
| «Этот аккаунт Авито уже подключён» | Вы уже подключали его | Откроются настройки уже подключённого аккаунта |

После двух последних ошибок аккаунт всё равно подключён: объявления и автозагрузка работают, не работают только чаты.
