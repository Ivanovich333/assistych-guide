# Регистрация и вход

1. Откройте **assistych.ru** и нажмите «Войти / Регистрация».
2. Зарегистрируйтесь по почте и подтвердите вход — или войдите через **ВКонтакте** / **Яндекс**, если вам так удобнее.
3. После входа вы попадёте в Панель управления.

![Экран входа](../.gitbook/assets/screen-login.png)

![Панель управления](../.gitbook/assets/screen-dashboard.png)

{% hint style="info" %}
Один кабинет = один бизнес. Если у вас два бизнеса, заведите второй аккаунт на другую почту.
{% endhint %}
