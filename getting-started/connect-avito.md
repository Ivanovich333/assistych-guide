# Подключение Авито

1. В левом меню откройте раздел **Авито → Мои аккаунты**.
2. Нажмите «Подключить Авито» и авторизуйтесь в своём аккаунте Авито.
3. После подключения аккаунт появится в списке.

![Подключение Авито](../.gitbook/assets/screen-connect-avito.png)

{% hint style="info" %}
Для управления ставками и автозагрузки у аккаунта Авито должен быть доступ к соответствующим разделам Авито (Pro-кабинет и автозагрузка).
{% endhint %}

{% hint style="warning" %}
**Чаты в реальном времени** требуют платной подписки «API мессенджера» в кабинете Авито. Без неё сообщения подтягиваются фоновой сверкой с задержкой до часа, и бот не может отвечать мгновенно.
{% endhint %}

Интеграция привязана к агенту: чтобы бот отвечал в чатах, агент должен быть включён. Выключенный агент — режим «только мониторинг»: вы всё видите, но бот не отвечает.
