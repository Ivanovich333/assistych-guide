# Подключение Авито

1. В левом меню откройте раздел **Авито → Мои аккаунты** и нажмите **«Подключить аккаунт»**.
2. Введите **Client ID** и **Client Secret** из вашего кабинета Авито для разработчиков (avito.ru/professionals/api). Доступ к API Авито даёт на платных тарифах для бизнеса.
3. После подключения аккаунт появится в списке и в переключателе аккаунтов — все разделы Авито показывают данные выбранного аккаунта.

Второй аккаунт подключается так же — кнопкой «Подключить аккаунт» или через раздел **Интеграции → Авито → «Подключить Авито»**.

## После подключения

- На карточке аккаунта видны статус, число объявлений и время последней синхронизации.
- **Автоответы** включаются и выключаются на карточке аккаунта.
- Если у аккаунта уже есть переписка, нажмите **«Подтянуть историю»** — сообщения клиентов из истории Авито появятся в чатах в течение нескольких минут (дубли исключаются).

{% hint style="info" %}
Для управления ставками и автозагрузки у аккаунта Авито должен быть доступ к соответствующим разделам Авито (Pro-кабинет и автозагрузка).
{% endhint %}

{% hint style="warning" %}
**Чаты в реальном времени** требуют платной подписки «API мессенджера» в кабинете Авито. Без неё сообщения подтягиваются фоновой сверкой с задержкой до часа, и бот не может отвечать мгновенно.
{% endhint %}

Интеграция привязана к агенту: чтобы бот отвечал в чатах, агент должен быть включён. Выключенный агент — режим «только мониторинг»: вы всё видите, но бот не отвечает.
